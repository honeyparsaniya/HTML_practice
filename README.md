# HTML Practice

This repository contains my HTML practice programs while learning the basics of HTML5.

## Topics Covered

### 1. Text Tags
- Headings (`<h1>` to `<h6>`)
- Paragraph (`<p>`)
- Bold (`<b>`)
- Strong (`<strong>`)
- Italic (`<i>`)
- Emphasis (`<em>`)
- Underline (`<u>`)
- Mark (`<mark>`)
- Small (`<small>`)
- Delete (`<del>`)
- Insert (`<ins>`)
- Subscript (`<sub>`)
- Superscript (`<sup>`)
- Span (`<span>`)

### 2. List Tags
- Ordered List (`<ol>`)
- Unordered List (`<ul>`)
- Description List (`<dl>`, `<dt>`, `<dd>`)

### 3. Table Tags
- Table Creation
- Rows and Columns
- `rowspan`
- `colspan`

### 4. Image Tag
- Displaying Images
- Image Attributes

### 5. Video Tag
- Embedding Videos

### 6. Details & Summary Tag
- `<details>`
- `<summary>`

### 7. Fieldset Tag
- `<fieldset>`
- `<legend>`

### 8. Input Tags

#### Basic Inputs
- Text
- Password
- Number
- Email
- Telephone
- URL
- Search

#### Selection Inputs
- Radio Button
- Checkbox
- Color Picker

#### Date & Time Inputs
- Date
- Time
- Week
- Month
- Date-Time Local

#### File & Form Controls
- File Upload
- Submit Button
- Reset Button
- Normal Button
